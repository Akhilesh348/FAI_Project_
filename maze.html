Maze Navigation (GridWorld Pathfinding)

Compare how different RL algorithms learn to navigate through mazes

Q-Learning Algorithm

Off-policy TD control algorithm that learns the optimal action-value function Q*(s,a). It explores quickly and converges stably, making it ideal for grid-based navigation.

Update Rule: Q(s,a) ← Q(s,a) + α[r + γ max Q(s',a') - Q(s,a)]

SARSA Algorithm

On-policy TD control algorithm that learns the value of the policy being followed. It tends to learn more cautious policies as it considers the action it will actually take.

Update Rule: Q(s,a) ← Q(s,a) + α[r + γ Q(s',a') - Q(s,a)]

Monte Carlo Algorithm

Episode-based learning that updates Q-values using complete episode returns. No bootstrapping - learns from actual outcomes. Better for episodic tasks.

Update Rule: Q(s,a) ← average of returns following (s,a)

Advantage: No bias, learns from complete trajectories

Deep Q-Network (DQN)

Uses a neural network to approximate Q-values, allowing it to handle larger state spaces. Employs experience replay and target networks for stable learning.

Key Innovation: Function approximation with deep learning
