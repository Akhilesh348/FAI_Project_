Memory Management (Block Relocation Puzzle)

Learn to relocate memory blocks optimally without overlap

Q-Learning Algorithm

Off-policy TD control learning optimal memory allocation strategies. Explores first-fit, best-fit, worst-fit algorithms and when to defragment memory.

Actions: First-fit | Best-fit | Worst-fit | Compact | Reject Request

SARSA Algorithm

On-policy TD control learning conservative allocation policies. Balances allocation success with fragmentation management.

Focus: Safe allocations that minimize future fragmentation

Monte Carlo Algorithm

Episode-based learning evaluating complete memory management sequences. Learns from full process lifecycles and deallocation patterns.

Strength: Understanding long-term memory utilization patterns

Deep Q-Network (DQN)

Neural network approximation handling complex memory state spaces. Learns sophisticated allocation patterns from experience replay.

Key Innovation: Handles high-dimensional memory configurations
