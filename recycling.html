Recycling Separator (Waste Sorting Puzzle)

Sort paper, plastic, and metal into pure bins using strategic moves

Q-Learning Algorithm

Off-policy TD control learning optimal sorting sequences. Discovers which moves lead to sorted bins most efficiently.

Challenge: Learn to use empty bins strategically for temporary storage

SARSA Algorithm

On-policy TD control learning cautious sorting strategies. Avoids getting stuck by considering current policy.

Focus: Safe moves that don't create unsortable situations

Monte Carlo Algorithm

Episode-based learning evaluating complete sorting sequences. Learns from entire solutions without intermediate updates.

Strength: Understanding full sorting strategies

Deep Q-Network (DQN)

Neural network approximation handling complex bin configurations. Generalizes sorting patterns across different initial states.

Key Innovation: Scales to larger bin counts and items
